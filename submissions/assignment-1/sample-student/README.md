# Sample Submission

This folder shows the expected **format** for Assignment 1, not the correct
answers. It contains:
- `answers.md`: Every label filled in with example placeholder text, so you
  can see how a complete answer file should look. The choices and ordering
  in this file are not necessarily correct — work out your own answers using
  the assignment brief.
- `SAMPLE_PR.md`: An example of what the filled-out Pull Request template
  should look like when submitting.

**Do not copy this folder's answers.** Create your own folder with your
GitHub username under `submissions/assignment-1/`, and fill it in with your
own reasoning.
